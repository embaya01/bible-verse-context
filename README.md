# Bible Verse Context

Plain-English context for any Bible chapter — historical, cultural, and devotional background generated by Claude and cached in Supabase.

See the project Live at [https://bible-verse-context.vercel.app/](https://bible-verse-context.vercel.app/)

## Stack

- Next.js 16 (App Router) + React 19
- Tailwind CSS
- Anthropic SDK (`claude-sonnet-4-6` with prompt caching)
- Supabase Postgres (cache only)
- TypeScript + Zod

## Getting started

1. **Install deps** (already done if you scaffolded with this repo):
   ```bash
   npm install
   ```

2. **Create the Supabase table**: open the SQL editor in your Supabase project and run [`lib/db/schema.sql`](lib/db/schema.sql).

3. **Configure env vars**: copy `.env.local.example` → `.env.local` and fill in:
   - `ANTHROPIC_API_KEY` — from <https://console.anthropic.com/settings/keys>
   - `NEXT_PUBLIC_SUPABASE_URL` — Supabase project URL
   - `SUPABASE_SERVICE_ROLE_KEY` — Supabase service role key (server-only)

4. **Run the dev server**:
   ```bash
   npm run dev
   ```
   Open <http://localhost:3000>.

## Project structure

```
app/
  page.tsx                    landing + input form
  [book]/[chapter]/page.tsx   result page (server-rendered, cache-aware)
  api/generate/route.ts       JSON endpoint (rate-limited, ceiling-capped)
  about/page.tsx              about + theological-framing disclosure
components/
  reference-form.tsx          book/chapter picker (client)
  context-sections.tsx        the four context cards
lib/
  bible/books.ts              66 books, chapter counts, slug parsing
  claude/system-prompt.ts     prompt + model constant + version
  claude/generate.ts          Anthropic call + zod-validated parsing
  cache/chapter-context.ts    Supabase read/write
  supabase/client.ts          service-role client + payload types
  rate-limit.ts               in-memory IP throttling + daily ceiling
  db/schema.sql               run-once Supabase setup
```

## Notes for production

- The in-memory rate limiter in `lib/rate-limit.ts` is per-instance only. Swap for Upstash/Vercel KV before any meaningful traffic.
- Set Anthropic spend alerts as a backstop.
- After the cache warms (~1,189 chapters × prompt versions), per-request cost approaches zero.
